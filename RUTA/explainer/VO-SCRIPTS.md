# Voiceover scripts

Episodes 1 and 2 are Ruta's own text. The only changes are for Matilda's voice:
typos, product names spelled as said (Клод, Баффер, Ноушн), numbers as words,
and commas for pauses. The captions are suggestions. Episodes 3–5 are still
Claude's drafts in the old style, which Ruta is rewriting. Style:
[`VO-STYLE.md`](VO-STYLE.md).

## 1 · Монтаж (Ruta, 103 words, 6 steps)

| caption | voiceover |
|---|---|
| Записала й *виклала* | Ти записала відео та виклала його в інстаграм. |
| Але *ніхто* не дивиться | Але воно з паузами та помилками, і його ніхто не дивиться. |
| Вирізаєш *зайве* | Тоді ти вирізаєш все непотрібне, |
| Але все ще *нецікаво* | але воно все ще не цікаве. |
| Додаєш *анімації* й субтитри | Ти додаєш туди анімації та субтитри. |
| *Година* на рілс | Тепер кожен рілс займає в тебе годину монтажу, і ти вигоряєш. |
| Наймаєш *монтажера* | Тоді ти наймаєш монтажера, |
| *30 €* за рілс | але кожен рілс коштує тридцять євро, і ти улітаєш в мінус. |
| Монтаж у *Claude* | Тоді ти налаштовуєш монтаж у Клоді: показуєш йому приклади рілсів, завантажуєш потрібні скіли та віддаєш своє відео. |
| Але лише на *комп’ютері* | Він монтує самостійно, але лише на комп’ютері. |
| *Хмара* → Монтуєш *з телефона* | Тоді ти виводиш це все на хмару, і тепер ти можеш монтувати з телефона коли завгодно. |

## 2 · Аналіз контенту (Ruta, 110 words, 5 steps)

| caption | voiceover |
|---|---|
| Постиш *щодня* | Ти постиш контент кожного дня, |
| Один *залітає*, інший — ні | але один рілс залітає, а інший — ні. |
| Дивишся *статистику* | Тоді ти дивишся в статистику і намагаєшся проаналізувати. |
| І нічого *не розумієш* | Але це займає забагато часу, і ти нічого не розумієш. |
| *Скріншоти* — в Claude | Тоді ти робиш мільйон скріншотів та відправляєш їх у Клод. |
| Але *щотижня* сама | Він усе проаналізував, але тобі треба робити це кожного тижня самостійно. |
| *Buffer* + Claude | Тоді ти підключаєш Баффер до Клода і просиш його проаналізувати контент. |
| Пояснюєш *щоразу* | Він дає тобі аналіз, але тобі кожного разу треба пояснювати, що це були за рілси і як саме аналізувати. |
| Notion + *скіл* + рутина → Щонеділі — *звіт* | Тоді ти підключаєш свій контент-план у Ноушені до Клода, зберігаєш правила аналізу в скіл і налаштовуєш рутину. Тепер кожну неділю ти отримуєш повний звіт контенту з новими ідеями. |

## 3 · Ідеї для контенту (Claude's draft, old style)

| caption | voiceover |
|---|---|
| *Порожня* сторінка | Якщо сісти записати рілс, у тебе є порожня сторінка. |
| І *нічого* не приходить | Але нічого не приходить у голову. |
| Ідеї — в *нотатки* | Тож ти зберігаєш ідеї в нотатки, а чужі рілси — в збережене. |
| Нотатки — *кладовище* | Але нотатки стають кладовищем, а збережене вже не передивишся. |
| Ідеї від *Claude* | Тож ти просиш Клода накидати ідей. |
| Але вони *загальні* | Але ідеї загальні, а українською звучать неприродно. |
| Бренд, аудиторія, *приклади* | Тож ти даєш йому свій бренд, аудиторію і приклади хороших сценаріїв. |
| Звучить *не як ти* | Але навіть так текст звучить не як ти. |
| Пояснюєш *свій голос* | Тож ти пояснюєш йому свій голос: як ти говориш і яких слів не вживаєш. |
| І щоразу — *з нуля* | Але в кожному новому чаті пояснюєш усе з нуля. |
| Це — *скіл* → Наговорюєш *тему* → Сценарій — *твоїми словами* | Тож ти зберігаєш це один раз. Це — скіл. Тепер ти просто наговорюєш тему, а він пише сценарій твоїми словами. |

## 4 · Каруселі (Claude's draft, old style)

| caption | voiceover |
|---|---|
| Карусель у *Canva* вручну | Якщо зібрати карусель у Канві вручну, у тебе є карусель. |
| Це *цілий вечір* | Але на неї йде цілий вечір: слайд за слайдом, шрифт за шрифтом. |
| Робиш *шаблон* | Тож ти робиш шаблон. |
| Але *текст* — сама | Але весь текст на кожному слайді однаково пишеш сама. |
| Текст пише *Claude* | Тож текст пише Клод. |
| Звучить *як усі* | Але звучить він як усі, тільки не як ти. |
| Вчиш його *своєму голосу* | Тож ти вчиш його своєму голосу. |
| Але *дизайн* — руками | Але дизайн однаково збираєш руками. |
| Дизайн від *Claude* | Тож ти просиш Клода зробити ще й дизайн. |
| *Негарно* і щоразу по-різному | Але виходить негарно, щоразу по-різному, а в новому чаті він усе забуває. |
| *Дизайн-система* + скіл → Кожна карусель — *твій стиль* → І одразу в *Canva* | Тож ти один раз збираєш кольори, шрифти й правила в один файл. Це — дизайн-система, і скіл бере її щоразу. Тепер кожна карусель у твоєму стилі, прямо з телефона, і одразу в Канві. |
